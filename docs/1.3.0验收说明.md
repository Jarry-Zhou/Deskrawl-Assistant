# 1.3.0 验收说明

适配基准：Deskrawl 1.0.2b / Steam build 25895065，Windows x64。

## 本版改动

- 在托管模式的重复刷图中增加“观星 · 只刷高价值奖励”，默认关闭，保存后生效。每局从完整且与当前连接、关卡和难度一致的原始计划判断，任意所选奖励命中即正常完成。
- 神圣、黑雾传说装备、符文套装和宏伟符文固定保留；传说（包括远古）四主词条全对、满足启用筛选规则、稀有／优秀符文及任意宝石默认勾选，可以取消。四主词条判断排除基础护甲、武器速度和武器伤害，不要求副词条命中。
- 未命中时优先在同难度的两张配置关卡之间直接切换；同一关卡、跨难度或连续拒绝时回城整理后重新进入。角色攻击、采集、场景切换或在线同步时等待；明确拒绝允许有限重试，已提交但结果未确认的切图不重复发送。
- 已生成地面或马车奖励时先回城收取并整理；计划不完整、物品待核验或来源关卡已变化时不跳过。保留现有高价值保护、整批先锁定后处置和主城奖励未清空不入图的检查。
- 两张图分别保留当前轮已成功通关次数。观星跳过、死亡、失败或中途退出不计入；重试等待期间已确认的通关也计数，原生复刷不会漏记或重复计数。
- 高价值掉落监控数量改为实际留档目录中的 JSON 文件数，移走或删除后下一次状态刷新同步减少；不删除或重写旧留档。

## 验证范围

- 1008 项 Python、79 项前端测试通过。发行源码使用离线用例验证奖励选项、完整性和连接身份、保护时序、状态变化、拒绝重试、回执、通关计数及设置迁移；前端验证规则选项与默认配置。
- 本机实测在副本中完成“炼狱 · 灰烬之冠4 → 3 → 4”，中间不回城。短暂拒绝后切换成功，同一图重新生成关卡身份和掉落计划；结束后返回主城，测试掉落保留，未执行出售、分解、购买、换装或配置覆盖。
- 发布前使用隔离目录验证单文件独立窗体、显式测试入口、默认关闭与配置保存恢复、内置源码及资源；发布后验证公开更新下载和 NAS 归档的大小及 SHA256。

微信远程控制仍暂停，不提供入口、接口或组件。升级保留已有规则、托管、成长及整理配置；新程序启动后由用户连接游戏并启动托管。

## 使用方法

在“托管模式 → 自动刷图／推图”选择“重复刷图”，配置一张或两张关卡，开启“观星 · 只刷高价值奖励”，勾选所需可选奖励并保存托管设置，然后启动。该功能不作用于自动推图。

## 发布方式

GitHub Release 仅提供 `Deskrawl-Assistant-v1.3.0.exe`。本机完整目录另附使用说明、第三方许可及官方 WebView2 安装器；与 GitHub 相同的 exe 归档至指定 NAS 共享目录。
