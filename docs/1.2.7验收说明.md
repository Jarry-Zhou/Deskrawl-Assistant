# 1.2.7 验收说明

用户已验收原生复刷计数递增；单文件打包和隔离运行验证通过。

适配基准：Deskrawl 1.0.2a，Steam build 25842017，Windows x64。

## 本版改动

- 修复在主城连接游戏时，技能控制器未加载导致托管按钮变灰的问题。天赋、生活技能、灵魂碎片及商人解锁独立读取；技能尚未读到时等待，不阻断其他托管功能。技能页显示实际等待原因，操作前继续核验技能栏和读取一致性。
- 隐藏“刷图推荐”和“经验收益”，保留装备筛选、背包与仓库、托管模式、掉落预览和日志五个页签。停用经验采样、推荐及耗时校准后台任务，相关接口返回停用状态；更新程序不再等待已停用的采样。
- 保留历史报告数据库；托管仍能读取关卡、难度和通关进度。用户原有筛选规则、成长预设及整理配置继续使用，普通启动的功能开放范围沿用 1.2.6。
- 原生复刷直接启动下一局时，根据已确认的最后一波击杀与地图通关记录累计局数；同一局的后续结算或回城保留状态不重复计算。没有完成证据的波次、其他地图和难度不计数；批次内不主动逐局回城，到设定局数才切图。

## 验证范围

- 944 项 Python、72 项前端测试，覆盖主城技能未加载、技能切换等待、启动阻断原因、停用接口、无报告数据库初始化和后台任务，以及更新流程。新增原生复刷的判定、去重、同步等待及 300 局双图循环检查。
- 核验当前游戏文件中的成长及商人原生接口布局、签名和代码基准。主城读取修复已进行只读验证，本次发布不操作正在运行的游戏。
- 对当前游戏进行 240 秒只读观测，记录 152 个状态变化；按 2 秒间隔回放确认 3 局计数，300 局批次内没有逐局回城，缩短为 2 局时正确规划切换至另一张图。没有安装调度器或执行任何游戏操作；实际运行中的旧版计数没有修改。
- 修复开发版沿用用户保存的 46 套筛选规则与两张图各 300 局配置，启动时未修改配置文件。用户运行托管后确认计数正常递增；完整 300 局双图轮换由自动测试覆盖，未声称完成整轮实机验收。

## 打包验证

- 单文件 exe 在独立数据目录、中文和空格路径、无外部 Python 的环境通过普通窗体及显式测试入口检查；保存规则、成长预设、购买和整理设置后重启，配置完整保留，自动功能默认暂停。重复启动复用原服务。
- 打包版保留五个页签，报告接口拒绝访问且不生成报告数据库。打包模块和静态资源与发布源码逐项核对，包含 573 张物品图标、319 张成长图标及 14 张界面纹理，不包含个人配置、快照或日志数据库。

## 发布方式与核验

- GitHub Release 仅提供 `Deskrawl-Assistant-v1.2.7.exe`，本地完整目录另带使用说明、第三方许可及官方 WebView2 安装器；两个目录的 exe 内容一致。
- 发布时核验 Windows 版本信息、文件大小和 SHA256，以及匿名检查更新与下载。构建、隔离启动、资源一致性及公开下载的机器验证记录保存在本地 `release/`，不随 exe 分发。

神秘商人消费与猎人战斗天赋的实机结果沿用 [1.2.6 验收记录](1.2.6验收说明.md)；生活技能、技能切换和其他职业天赋的实机写入范围没有扩大。本次打包验证使用隔离目录，不重启正在运行的助手，也不修改用户配置。
