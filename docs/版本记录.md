- 固定保护神圣、黑雾装备及套装／宏伟符文，禁止出售和分解；主城地面／马车奖励未清空或保护物品未收纳时禁止入图，规划、执行和原生调用分别复核。
- 主动停止托管先回城整理，另有暂停／立即停止；托管期间可选择启用规则监控与自动整理，共用串行工作通道。
- 增加本次累计掉落和按品质出售／分解计数，读取游戏系统日志核对低品质自动处置，使用原生记录核对传说以上，助手回执单独去重；修正品质颜色，远古与普通传说共用橙色。
- 修复主城空关卡记录、64 位 GC 句柄截断、回城结算入口与异步切换确认问题，保留构建指纹校验和不确定结果停止重发。
- 依据已确认实机回执开放换装、回城入图、地面拾取、开箱和分解。主动出售和难度切换保留 `--test-managed` 实验入口，不标记为已验收；普通启动不自动连接或托管。
- 708 项 Python 与 40 项前端测试通过；验证范围见 [1.2.2 验收说明](1.2.2验收说明.md)。
