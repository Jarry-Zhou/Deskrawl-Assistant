# 1.3.2 验收说明

适配基准：Deskrawl 1.0.2b / Steam build 25895065，Windows x64。

## 本版修复

- 日志后新增“交流&反馈”页签，展示QQ群二维码、群号及交流反馈说明；图片内置，可离线显示。
- 托管启动按钮随输入立即重新校验。修正背包回城阈值、双图局数后，无需切换观星开关或移出输入框即可刷新按钮状态。
- 按钮不可用时直接显示配置、关卡读取、神秘商人解锁、动作能力或服务端校验原因；保存失败的错误保持可见。修改尚未保存且服务端仍使用旧设置时提示先保存。
- 回城请求被游戏接收不再等同于已回城。传送、场景切换或在线同步仍进行时等待；完整读取确认连续稳定、没有待处理请求且确实仍在关卡后，重新规划并有限重试。
- 连续三次回城被打断，或恢复等待达到两分钟上限，进入可恢复暂停，保留本次统计。点击“继续托管”后重新读取实际场景；角色已迟到回城时不再重复发送回城请求。
- 等待回城期间仍记录有效成功通关回执，不重复计数。旧观星回城意图遇到原生复刷的新一局时重新判断奖励，防止误跳高价值局或记入不存在的跳过。
- 主动停止后的回城恢复仍以整理后停止为目标，不重新入图。场景未知、会话变化或结果不明确时停止重复动作。

## 使用与验证

升级保留已有规则、托管策略和统计配置。观星新用户默认关闭，需保存设置后手动启动；原生动作能力与游戏适配要求继续生效。

自动验证覆盖按钮输入与错误显示、回城拒绝／打断／迟到回执、持续同步、三次失败暂停、恢复继续、结束托管及观星计数。发行 exe 使用隔离数据和本机统计回执服务验证独立启动、资源及保存重启；不操作正在运行的游戏，不向公网发送测试身份。

本次新增回城恢复流程通过离线模拟与浏览器回归，尚未进行新版实机回城恢复验收。对于结果不明确的出售、分解等动作，仍保留原有保护，不盲目重复请求。

微信远控仍暂停，不包含其入口、接口或组件。GitHub Release 仅提供 `Deskrawl-Assistant-v1.3.2.exe`。
