# 1.2.8 验收说明

适配基准：Deskrawl 1.0.2b，Steam build 25895065，Windows x64。

## 本版改动

- 神秘商人购买与补货在提交前检查游戏的在线同步队列；尚有待处理请求或保存正在进行时，等待同步完成后重新规划，避免游戏原生购买入口直接返回造成托管停止。检查结果加入原生提交前的一致性校验。
- 成长和商人动作未确认时，日志记录具体动作、预期件数、读取到的新增物品、灵魂碎片变化及读取异常，便于排查。已提交但结果不明的操作仍停止，不自动重复购买或加点。
- 托管页面的监控整理、换装、刷图、商人、成长规划和回城整理分别支持折叠；标题显示启用状态、配置摘要及刷图进度。天赋、生活技能、技能规划可独立收纳，保存入口放在配置上方。
- 本机保存展开偏好；轮询不会重置展开状态，折叠不改变启用开关、预设或未保存状态。生活技能树在展开后正常居中。
- 更新游戏 1.0.2b 的静态资源、字段布局和原生接口适配基准；新增“狼人毛皮”材料的名称、描述和图标，“苦痛锯齿巨剑”与“裂魂之刃”的职业范围新增武僧。宝石、符文效果及词条池保持一致，物品图标按新版游戏素材刷新。
- 按新版游戏更新属性上限：冷却缩减 80%，总伤害减免及各类型伤害减免 90%；属性转换和换装比较先使用封顶后的属性，避免虚增升级收益。攻击速度和武器速度不增加额外上限。

## 验证范围

- 游戏文件核验 42 个动作类型、30 个原生入口及 6 个导出；入口的归一化指令与上一版一致，更新实际名称、token、代码地址和未初始化类型引用。16,302 项代码特征与新基线逐项匹配，保留原有保护和功能开放范围。
- 独立只读连接游戏 1.0.2b，完整读取背包与仓库、12 件角色装备、76 个关卡及 3 种难度、成长数据和 10 类商人实际报价。原生动作调度器没有安装或执行；掉落预览在主城返回等待在线关卡状态。
- 隔离文件模拟字段／类型改名及全局地址移动，自动适配通过，不修改游戏安装文件。
- 托管折叠界面通过 1600、900、480 像素宽度离线浏览器验证，鼠标、键盘、刷新恢复与草稿保持正常。
- 954 项 Python、77 项前端测试通过，覆盖商人同步等待、严格回执与禁止重复购买、属性封顶和换装增益、旧类型引用拒绝、物品资源、折叠交互与预设保存。
- 单文件独立窗体及显式测试入口在隔离目录启动、重复启动、退出和重启检查通过；无需外部 Python，既有规则、天赋／技能、商人配置和整理偏好可保存恢复。包含 574 张物品图标及 333 张成长图标／纹理，不包含个人配置、快照、日志或预研模块。

本次检查与打包使用只读游戏检查及隔离配置，不重启当前游戏或助手，不修改用户物品及本地配置。原生动作本次核验范围为游戏文件与地址校验，未重新执行购买、换装或出售等实机动作。

观星与微信远程控制仍处于本地预研阶段，本版不提供入口或执行功能。功能开放范围沿用 1.2.7；筛选、搬运与托管保护规则继续生效。

## 发布方式

GitHub Release 仅上传 `Deskrawl-Assistant-v1.2.8.exe`；本地完整目录附带使用说明、第三方许可与官方 WebView2 安装器。发布后核验公开下载、自动更新识别和 NAS 归档文件的大小与 SHA256。
