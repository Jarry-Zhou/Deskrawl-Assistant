# 1.3.3 验收说明

适配基准：Deskrawl 1.0.2b / Steam build 25895065，Windows x64。

## 功能与修复

- 自动整理和托管回城整理共用符文、宝石存放页，修改任一处即时同步草稿，在任一处保存即可。旧用户首次加载以已保存的托管配置为准；没有托管配置时沿用自动整理配置。其他策略保持原值，读取失败保留原文件。
- 顶部显示游戏运行状态，可用 Steam 启动游戏；关闭前二次确认并复核进程身份，通过正常关闭请求退出，先停止并等待助手写入操作完成。
- 重复刷图难度增加“神话裂隙”，关卡显示层数，只列出已解锁层。进入前再次核验解锁、材料和关卡身份，支持与普通地图轮换；自动推图仍按普通／噩梦／炼狱推进。
- 修复神话裂隙层数读取中错误访问 WaveManager 的问题，区分原生复刷的局次与成功结算，退出未通关不计数。
- 双图最后一局在确认胜利后先收取地面奖励，金币／药水优先、装备等随后、宝箱最后。只有结算已确认且连续完整读取地面为空后才离开；临近传送时新出现奖励会取消尚未提交的回城。背包满则先按已有配置腾出空间，无法腾出时原地暂停。
- 修复金币将材料数量误作金额导致的“物品结果尚未确认”：读取原生金币金额，结合原掉落消耗状态与金币到账核验，兼容同时拾取多堆金币。
- 药水按药瓶充能及原掉落消耗核验，满充能或自动喝药不再误用角色生命值判断；装备仍核对实际收到的唯一编号，堆叠物品核对数量。仅回读确认，不重复提交结果不明的动作。

## 配置与验证范围

已有个人规则、换装、购买、处置与成长配置继续保留。神圣／黑雾装备和套装／宏伟符文保护、神圣禁止自动穿戴继续生效。观星默认关闭；程序不会自动连接、启动游戏或开启托管。

发行源码运行 Python 与前端回归测试；单文件发行程序用隔离数据目录和本机统计回执服务验证独立窗体、资源、配置保存与重启，不向公共统计服务发送测试身份，也不操作正在运行的游戏或助手。最终数量见 Release 说明。

金币修复使用实测失败日志中 2,312 金币到账的数值回放，覆盖同时到账、未消耗／未到账拒绝及“金币→装备→空地确认→回城”衔接；药水覆盖满充能与自动消耗。最终拾取修复尚待玩家继续实机验证，不将离线回放等同实机验收。

微信远控保持暂停，不包含入口、接口或组件。GitHub Release 仅提供 `Deskrawl-Assistant-v1.3.3.exe`。
