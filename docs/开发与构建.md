# 源码运行与构建

使用 Windows 和 64 位 Python 3.12；已验证构建环境为 Python 3.12.14。日常使用直接下载 [Release](https://github.com/awesomehy/Deskrawl-Assistant/releases) 的 exe 即可。

## 从源码运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-runtime.txt
.\.venv\Scripts\pythonw.exe run_assistant.pyw
```

创建环境并安装依赖后，也可双击 `启动装备助手.cmd`。源码版个人数据位于工作目录的 `config/` 和 `data/runtime/`，不纳入仓库。

## 自动测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
node --test tests/test_inventory_tools.js tests/test_automation_ui.js tests/test_managed_mode_ui.js tests/test_loot_preview_ui.js
```

测试使用合成或脱敏用例与模拟内存，不要求运行游戏。各版本的实机验证范围另见[版本记录](版本记录.md)及对应验收说明。

## 构建单文件 exe

```powershell
python -m venv .build-venv
.\.build-venv\Scripts\python.exe -m pip install -r requirements-build.txt
Invoke-WebRequest -Uri 'https://go.microsoft.com/fwlink/p/?LinkId=2124703' -OutFile 'packaging/MicrosoftEdgeWebview2Setup.exe'
.\.build-venv\Scripts\python.exe tools/build_exe.py
```

构建输出到 `release/`，包括单文件 exe、使用说明、第三方许可和可选的官方 WebView2 安装程序。资源按白名单打包，包含必要静态字典、页面和 573 张图标（209 张装备、36 张宝石、199 张符文、129 张其他物品），不包含个人规则、快照、高价值掉落留档、日志数据库或游戏程序。GitHub Release 仅上传 exe。

```powershell
.\.build-venv\Scripts\python.exe tools/smoke_exe.py --desktop
```

上述独立窗体检查使用隔离数据目录，不连接游戏。`--connect-game` 可另外验证真实只读连接，仅在明确准备好受支持游戏时使用；它不执行锁定或搬运。

## 维护游戏适配

维护新基准前先人工核验读取、锁定、保存、搬运与资源，再使用 `tools/build_compatibility_baseline.py` 更新基准。未知版本不会自行生成或覆盖可信基准。`tools/verify_auto_compatibility.py` 使用 `build/` 下的文件副本模拟字段／类型改名及地址移动，不修改安装目录或游戏内存。

资源提取工具只读解析本地游戏文件，额外依赖 `requirements-unity.txt`；日常运行不需要 UnityPy。在线掉落预览和托管原生动作需要各自独立核验，不能通过普通读取适配来放宽。

## 主要目录

| 路径 | 内容 |
| --- | --- |
| `deskrawl_assistant/` | 游戏读取、物品操作、托管与本机服务 |
| `deskrawl_assistant/web/` | 网页界面和图标 |
| `data/` | 必要静态字典、类型及兼容配置 |
| `tests/` | 自动测试 |
| `packaging/`、`tools/` | 打包、资源提取与维护工具 |

v1.1.0、v1.1.1 的历史标签仅保存原始发行说明及许可；v1.1.2 起的标签提供对应版本完整源码。各版本适配与验证范围以发行说明为准。
