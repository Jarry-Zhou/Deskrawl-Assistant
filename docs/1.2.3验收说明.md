# 1.2.3 验收说明

适配基准：Deskrawl 1.0.2a，Steam build 25842017，Windows x64。

## 完整托管默认开放

在 1.2.2 已验证的回城、入图、换装、分解、开箱和地面拾取基础上，补充主动出售与难度切换的实机成功回执。精确构建校验通过后，普通启动开放所有八种原生动作，不再需要 `--test-managed` 参数即可配置出售、选择难度和跨难度推图。

默认不会自动连接游戏或开始托管，仍需连接、保存设置并手动启动。现有个人规则和整理设置继续优先；显式测试入口仅保留给后续维护，不用于绕过普通启动中的构建与物品保护检查。

## 补充实机验证

2026-10-11 使用与界面相同的托管执行器逐项测试，没有开启整套批量清理，也没有修改用户配置。

- 主动出售一件未锁定、未命中规则、未强化、未镶嵌且没有换装战力提升的 835 级普通传说「黑鸦反曲弓」。确认物品移除，金币 12,545,549 → 12,546,065，实际收入 516 金币。
- 在主城确认奖励清空后完成炼狱 → 噩梦 → 普通 → 炼狱；三次原生调用均确认实际难度变化，每次对应的 76 个关卡难度标记正确，最后恢复炼狱并留在主城。
- 上述验证确认当前运行中的结果，没有通过退出／重登另行验证服务器保存。私人快照及原始回执保存在本地，不随源码或安装包发布。

## 满背包校验容量修复

真实 40 格背包（28 件装备、12 个其他物品）在难度切换前生成 276 条校验记录，超出原来的 256 条限制，导致调用前停止。容量扩展至 384 条，保留全部身份、空格、奖励和品质检查，以及 16 KiB 原生邮箱分配上限、16 个调用和 8 个参数的限制。

本进程原生测试覆盖 300 条记录，确认第 256 条之后的校验失败仍阻止所有调用；编码测试继续拒绝容量和分配上限溢出。修改后满背包的三次真实难度切换全部成功。

## 保护与发布检查

- 神圣、黑雾装备和套装／宏伟符文必须收纳，禁止出售与分解；神圣装备禁止自动穿戴。
- 整批新装备完成筛选锁定后才能处置垃圾；主城地面、马车和必须收纳物品未处理完时禁止入图和切换难度。未解锁仓库页不会被当作空位。
- 游戏构建变化仍禁用原生动作；页面或规则导入不能关闭校验。未确认执行结果时停止，不重复提交。
- 711 项 Python 与 41 项前端测试通过；覆盖普通启动开放全部能力、构建变化拒绝执行，以及既有保护与托管流程。
- 单文件 exe 在隔离数据目录、中文／空格路径、无外部 Python 环境检查普通窗体与维护测试入口；不连接或操作正在运行的游戏。内置源码及资源与发布提交核对，包含 444 张图标，不含个人配置、装备快照或数据库。
- GitHub Release 只附 exe；公开下载由实际更新器核验大小、SHA256 和 Windows 版本信息。

战力比较沿用固定 Boss 面板估算，不完整模拟暗金特效、技能联动和实际 DPS。更多配置说明见 [托管模式说明](托管模式开发说明.md)。
