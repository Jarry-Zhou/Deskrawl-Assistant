# 基于 1.3.3 的托管续刷与换装修复

保留主干已有的神话裂隙层级标识与解锁读取、共享仓库、Boss 延迟掉落拾取保护、游戏启动退出功能。

## 改动

- 戒指和其他装备比较时，在同一角色基线上移除旧装备效果，再应用新装备效果。修复屠龙戒等条件属性留在比较基线中导致两枚戒指反复互换的问题；两个戒指槽位分别计算。
- 同图通关且背包空间足够时，通过游戏原始结算重开入口直接续刷。地图轮换按成功局数推进；切换世界难度仍先回城。
- 裂隙续刷沿用 1.3.3 的逻辑层级 ID，固定重开所选层，不升层。原生重新检查当前计划、RunPlan 层级与 WaveManager 304 层级字段。
- 推图死亡后保持失败关卡为目标，回城整理；启用自动换装时检查更高战力装备，再挑战同一关，不退回上一关。
- 直接续刷和回城共用主干的掉落结算、空地面静默间隔及拾取回执保护，避免漏掉延迟生成的 Boss 奖励。背包及待收马车奖励达到整理门槛时回城。

## 动作边界

普通同图续刷使用 CombatMapCompletionUI.fxe；裂隙续刷使用 MythicCompletionUI.hbm(false)。普通结算界面没有静态实例，采用最多 64 MiB / 1 秒的只读定位并缓存，每次重新检查存活状态及当前重开地图。所有原生方法沿用严格构建、字段和指令前缀校验。

连续入场请求绑定来源局 ID；实际读取到不同的新局 ID 后才确认成功。游戏自身自动重开导致旧计划变化时，原始请求不会再次执行。

## 验证边界

对齐版本执行离线回归和接口测试。本次对齐未在运行中的游戏执行动作；此前桌面 1.3.2 测试版的启动检查不等同于 1.3.3 实机验收。1.3.2 的旧实现保留在 feature/mythic-tier-and-continuous-farming 分支；本次 PR 以最新 1.3.3 为基线。

验证结果：1133 项后端回归、86 项前端测试通过；两个新增原生重开入口的签名和 24 字节文件前缀与当前游戏文件一致。
