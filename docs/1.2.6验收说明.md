# 1.2.6 验收说明

适配基准：Deskrawl 1.0.2a，Steam build 25842017，Windows x64。

## 本版功能

- 神秘商人按实际碎片容量触发回城，先整理奖励，再按部位件数循环购买。买满背包或用完预算后统一筛选处理；保留装备先锁定入库，未命中商品直接按品质出售／分解。默认 85% 触发、保留 0%，余额不足下一件商品即结束消费；购买件数默认全 0，保存的本地设置优先。
- 战斗天赋按当前职业保存目标页，最多 70 点，自动遵守前置、投入门槛及互斥节点，逐点学习并核对结果；可用点数不足时等待后续升级。页面使用游戏图标、层级进度条与点亮效果。
- 自动推图从最高已解锁难度与关卡出发，胜利前进、失败后退，持续重试；重复刷图可选一张或两张地图，分别配置局数和难度。
- 四职业技能组合与通用生活技能路径可预先规划、保存。生活技能先学习优先路径再最终点满，支持金币保留；技能到达解锁等级后切换，未解锁时沿用当前技能。
- 整理减少重复读取，复用已确认的出售／分解快照，成功后立即调度下一步。物品身份、规则、场景、在线同步及每件实际结果继续核验；修复暂态拒绝、过期选择、首次结算 UI 类型读取及物品品质配色。

## 开放范围

普通双击 exe 即可使用全部托管、神秘商人、战斗天赋、生活技能及技能切换功能，无需测试参数。新增开关默认关闭，仍需连接、配置、保存并手动启动。原有本地配置继续保留。

## 已完成验证

- 925 项 Python、68 项前端测试通过，覆盖预设上限与持久保存、商人批次与结束条件、重新规划、原生能力限制及全部既有物品保护。
- 原生接口文件核验通过：42 个类型、30 个方法的布局、签名和机器码与当前游戏基准一致。
- 猎人重置后，约 151 秒完成 70 次原生加点，13 个节点实际等级与保存目标完全一致，可用点数降至 0；没有改变金币、碎片、生活技能及技能组合，测试结束后完整恢复原配置。其他职业尚未进行实机加点验收。
- 按保存的购买及品质处置策略实测 76 件商品：57 件出售、18 件分解、1 件命中规则后锁定入库，垃圾入库为 0；剩余 5 碎片不足下一件戒指时正常结束，没有因保留 0% 阻塞。
- 单文件 exe 在隔离数据目录、中文和空格路径、无外部 Python 的环境检查普通独立窗体和显式测试入口，核验规则、成长预设、购买与整理配置重启后保留。该检查不连接或操作正在运行的游戏。
- 核对打包模块和静态资源与发布源码一致，包含 573 张物品图标、319 张成长图标及 14 张界面纹理、成长字典及更新脚本；个人规则、物品快照、日志和玩家数据库不随程序分发。
- GitHub Release 仅附 exe，校验大小、SHA256、Windows 版本信息及公开更新下载流程。

生活技能及技能切换尚未进行实机写入验收；按用户要求已在普通启动中开放。实机操作确认不等于游戏重启后的存档验证；新增成长及商人数据的存档重载仍待单独验收。已有固定保护、先筛选锁定后处置、主城奖励未清空不入图等规则继续生效。详细接口与开发记录见 [开发说明](1.2.6开发说明.md)。
