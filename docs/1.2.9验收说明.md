# 1.2.9 验收说明

适配基准：Deskrawl 1.0.2b / Steam build 25895065，Windows x64。

## 本版改动

- 合入 [PR #6](https://github.com/awesomehy/Deskrawl-Assistant/pull/6)：角色死亡后使用死亡界面原生返回主城入口，避免普通传送未取消自动复活计时而停留在关卡。界面未加载或已有复活／回城请求时等待，实际进入主城后才整理并续刷；死亡标记优先于过时的关卡成功状态。
- 黑雾装备隐藏词条不再作为整批奖励核验的阻断条件。在身份、物品实例和锁状态可靠时，先锁定并放入配置的装备仓库页，再按已有品质策略处理其他装备。普通装备词条待核验、身份不可靠或仓库容量不足时仍保留物品并等待处理；神圣、黑雾以及套装／宏伟符文保护继续生效。
- 允许安全锁定词条未揭示的黑雾装备。提交前继续核验物品唯一身份、实例、注册表、词条快照和布局，写入后核对锁状态，不揭示或改写属性。
- 修正高价值监控来源：已确认神秘商人购买的物品单独以商人来源留档，不再关联此前关卡计划；购买回执未完成时等待来源确认。已有留档原件不重写。
- 暂停后的继续操作重新开始奖励核验计数，避免沿用上一轮计数立即再次暂停。

## 验证范围

- 969 项 Python、77 项前端测试通过，覆盖死亡恢复、冷启动界面、自动复活竞争、回城后续刷、隐藏黑雾锁定／收纳、整批处置时序及商人留档来源。
- 本机游戏文件只读核验 43 个动作类型和 31 个方法，字段、入口 token、签名、地址及代码前缀与适配配置一致。
- 发布前验证单文件独立窗体、显式测试入口、配置保存恢复及打包源码与静态资源一致性；发布后核验公开下载、自动更新元数据和 NAS 归档的大小及 SHA256。

本次发布不执行游戏中的死亡回城、购买、出售、分解或换装动作；新增死亡恢复及黑雾锁定收纳流程已通过离线回归，实际游戏行为仍需用户验收。打包和启动检查使用隔离目录，不切换正在运行的助手。

微信远程控制开发已暂停，观星仍为本地预研，本版均不提供入口或执行功能。保留用户已有规则、托管、成长及整理配置，新程序启动后手动连接并启动托管。

## 发布方式

GitHub Release 仅提供 `Deskrawl-Assistant-v1.2.9.exe`。本机完整目录另附使用说明、第三方许可及官方 WebView2 安装器；与 GitHub 相同的 exe 归档至指定 NAS 共享目录。
